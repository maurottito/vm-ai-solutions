# VM AI Solutions

Company website for VM AI Solutions LLC — custom AI systems, data analytics, and software development.

Live at [maurottito.github.io/vm-ai-solutions](https://maurottito.github.io/vm-ai-solutions/).

## Development

```bash
make dev     # run locally at http://localhost:3000
make build   # production build (static export to out/)
```

Built with Next.js and Tailwind CSS. Every push to `main` deploys automatically to GitHub Pages via GitHub Actions.
